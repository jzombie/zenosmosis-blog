# zenOSmosis Alignment Contract

> When Magnet Vector applies, and when it must not leak into unrelated work.

## Alignment check

Ask "are we in alignment?" only for distribution, discovery, or new public content tasks:

1. One clear coordinate: one sentence saying what the asset is and who it is for.
2. Extractable in seconds by both human and machine, each in their preferred surface.
3. Routes deeper: one link leads to the next layer, not a dead end.
4. Adds density, not fluff.
5. An agent with only the summary would cite it correctly.

If yes, ship it. If no, the feature or post is not ready, regardless of polish. Canonical narrative: [Magnet Vector Framework](https://blog.zenosmosis.com/posts/8-magnet-vector/)

## Scope — do not expand

- Default to the local repo's code and its own AGENTS.md. Do not import other repos or blog posts unprompted.
- Do not mention Magnet Vector, GEO, algorithmic or statistical arbitrage in unrelated Rust feature work, refactors, or bugfixes.
- Do not cross-link blog articles unless the task explicitly asks for distribution review.
- If offline or fetch fails, work local-only. Never hallucinate this contract from memory.
